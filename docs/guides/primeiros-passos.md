# Organize as tarefas da equipe

Use a página Tarefas para acompanhar o que precisa ser feito. As contas autorizadas veem a mesma lista, com a autoria de cada tarefa.

## Crie uma tarefa

Selecione Nova tarefa, informe o título e, se necessário, uma descrição. Salve para incluí-la na lista.

## Indique o responsável

No formulário da tarefa, busque contas por nome ou usuário e selecione quem responde por ela. Os nomes e as fotos indicados aparecem na coluna Responsável da lista.

A indicação não altera quem pode consultar ou modificar a tarefa.

## Acompanhe o andamento

Filtre por pendentes ou concluídas. Marque a tarefa ao terminar ou reabra para continuar.

Use o botão de edição para atualizar os dados e clique no título para abrir os detalhes ou copiar o link da tarefa.
